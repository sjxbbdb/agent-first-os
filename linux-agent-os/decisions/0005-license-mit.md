# 决定 0005：许可证选 MIT
日期：2026-11-02　决定人：项目负责人确认（经总经理转达）

## 决定内容
1. 新增文件的占位许可证选 MIT（第一次的决定，原话「mit」）。
2. 同日补充（第二次的决定，经总经理转达）：仓库根放标准 MIT 全文的 `LICENSE`，整个仓库按 MIT，署名 `Copyright (c) 2026 agent-first-os contributors`。
3. 例外保持不变：`linux-agent-os/prototypes/proto1-landlock` 和基于 Linux 源码的衍生补丁仍是 GPL-2.0-only，不改成 MIT；第三方代码保留各自的许可证。
4. 已有 C 源码文件头先不动，清单交总经理，是否另开提交由总经理定。

## 来源
第一次：总经理问项目负责人「新增文件占位许可证想用什么」，项目负责人回答「mit」，总经理转达给我。第二次：总经理转达项目负责人批准的根 LICENSE、整个仓库按 MIT、署名写法和例外。两次都没有独立的原始记录，来源就是总经理的转达。

## 本决定的字面范围
- 决定了：许可证是 MIT；根 `LICENSE` 的全文与署名；整个仓库按 MIT；proto1-landlock 与 Linux 衍生补丁是例外。
- 没有决定：已有源码文件头要不要逐个加 SPDX（暂不动，清单见总经理处，另行决定）；第三方代码的具体清单与许可证文本（按各自许可证处理）。
- 「整个仓库按 MIT」按字面理解为仓库自己写的代码，不含上面写明的例外和第三方代码。
- 根 `LICENSE` 是 SPDX 官方 MIT 文本（来自 spdx/license-list-data 的 `text/MIT.txt`），只替换了第三行的版权行；落地时已逐字比对。
