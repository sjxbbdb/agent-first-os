# 决定 0004：M1 的代码基础、确认令牌签名、能力撤销
日期：2026-11-02　决定人：项目负责人确认（经总经理转达）

## 决定内容
1. 代码基础：第一里程碑（M1）在现有 agent-first-os 代码上改，不从零重写。
2. 确认令牌签名：用 Ed25519。内核里只放公钥，私钥放在确认端。
3. 里程碑内容：M1 按 `specs/native-kernel-m1.md` 里的草案做。能力先做成不可单独撤销（随任务回收），可单独撤销放到里程碑 2。

## 本决定的字面范围
- 第 2 项按字面理解：内核持有公钥，说明验签在内核里完成。如果实际要在用户态验签，需要另行说明，不按本条推定。
- 第 2 项没有规定公钥怎么进入内核、过期按什么时间算、重启后已批准未执行的动作怎么处理、随机数拿不到时怎么办。这些在 `research/round4-confirm-token-crypto.md` 第六节里只是调研的倾向，仍待决定，见 M1 规格的待定表。
- 第 2 项没有决定 Monocypher 钉哪个版本，仍待决定。
- 第 1 项只决定代码基础，没有决定「内核里放哪几个对象」，该项仍待决定。
- 第 3 项只说能力不可单独撤销，撤销的具体设计留到里程碑 2 再写。

项目负责人拍板，本条只记录结论，不重复讨论过程。
