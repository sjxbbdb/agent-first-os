## 本课教了什么

- C 源代码是方便人阅读的表达；
- CPU 最终执行机器指令；
- 源代码经过预处理、编译、汇编和链接，才形成可运行文件；
- `.o` 是目标文件，可能还包含未解决的符号或重定位信息；
- 最小构建主线是 `hello.c → hello.o → hello`。

## 学员表现

学员正确说明：C 代码不是 CPU 直接执行的机器语言；`.o` 尚未经过链接，不一定能独立运行；并正确排列了源代码、编译、目标文件、链接、运行的顺序。

## 平板笔记重点

- `★` C 源代码不是 CPU 直接执行的语言；
- `★` `.o` 是链接前的中间目标文件；
- `★` 构建主线：`hello.c → hello.o → hello`；
- `→` 编译/汇编负责转换，链接负责组合，运行阶段由操作系统加载。
