## 本课教了什么

- 程序通常按语句顺序执行；
- `int` 用于表示整数变量；
- 变量可以先定义并设置初始值；
- 赋值会把右侧结果保存到左侧变量；
- `b = a + 2` 使用的是执行当时的 `a`，之后修改 `a` 不会自动修改 `b`。

## 学员表现

学员正确回答了：

```c
int x = 4;
int y = x;
x = 9;
```

最终 `x = 9`、`y = 4`，并能说明代码是按行执行，第二行把当时的 `x` 值复制给了 `y`。
