## 已讲内容

- 代码片段需要一个程序入口才能独立运行；
- `main` 是默认的程序入口函数；
- `{}` 包住函数体；
- C 语句通常以 `;` 结束；
- `return 0` 表示从 `main` 返回并结束程序。

## 本节练习

```c
int main(void) {
    int x = 4;
    x = x + 3;
    return x;
}
```

补强练习中，学员正确追踪了 `n` 从 `1` 到 `5` 再到 `7` 的变化，并能说明每行读取的是执行当时的旧值。
