## 已讲内容

- 代码片段需要一个程序入口才能独立运行；
- `main` 是默认的程序入口函数；
- `{}` 包住函数体；
- C 语句通常以 `;` 结束；
- `return 0` 表示从 `main` 返回并结束程序。

## 本节练习

```c
int main(void) {
    int x = 4;
    x = x + 3;
    return x;
}
```

学员回答：程序返回值为 `7`，从 `main` 开始执行；把第二行执行后的 `x` 写成了 `4`，需要巩固“赋值执行后立即更新变量”的概念。
