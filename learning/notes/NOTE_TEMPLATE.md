# 课堂笔记模板

每一课只需要维护一份笔记。可以在平板笔记软件中完成，也可以把整理后的版本同步到本目录；没有同步时，以你发给老师的文字或照片内容为准。

```markdown
# 第 X 课：标题

## 今天要解决的问题
- 

## 【重点】必须记住
- 

## 我的理解
- 用自己的话解释：

## 例子 / 图
- 变量、内存、调用流程或状态变化图：

## 我还不确定
- 

## 课后复述
- 不看资料，我能解释：

## 对应证据
- 代码、命令、日志或截图：
```

## 记笔记规则

- 老师会在讲解中明确标出 `【重点】`；只需把这些内容优先写下来，不必逐字记录。
- 每节课至少写一个自己的例子或图，避免只抄定义。
- 把不懂的地方放进“我还不确定”，不要猜成确定结论。
- 下一次课开始前，先尝试完成“课后复述”；老师会根据复述结果决定复习还是继续。
- 笔记是学习证据和课程状态的一部分，但不要求一开始写得漂亮或完整。
