# Agent-First OS 课程验收协议

## 每课检查循环

```text
预测 → 实现 → 运行 → 解释 → 故障注入 → 复盘
```

每课至少包含一个参数或接口变体，以及一个从空目录重建的小任务。

## 每阶段证据包

```text
evidence/
  run.ps1 或 run.sh
  build-command.txt
  qemu-args.txt
  serial.log
  screenshots/
  fault-injection/
  report.md
```

`report.md` 必须区分事实、推断和未验证项。

## 阶段 Gate

每阶段 100 分，建议至少 80 分通过；权限、隔离和恢复阶段的关键项不能为零。

1. 概念与口头解释：20 分；
2. 关闭教程后的独立改动：30 分；
3. 可复现运行证据：20 分；
4. 故障注入与恢复：15 分；
5. 代码和架构审查：10 分；
6. 迁移到新参数或新场景：5 分。

## 防止复制教程

- **变体题**：修改地址、扇区、系统调用号、窗口名或权限范围；
- **白板复现**：不看代码画出 CPU、页表、IPC 或任务状态变化；
- **源码寻错**：从故意有 bug 的差异中定位并修复问题；
- **随机口试**：解释一条指令前后寄存器、页表项和失败边界；
- **独立重建**：从空目录重新构建同一阶段最小产物。

## 关键故障样例

| 阶段 | 必测故障 |
|---|---|
| 启动 | 错签名、错扇区、越界加载、长模式跳转错误 |
| 内存 | 非法指针、NX 违规、OOM、双重释放 |
| 中断 | 除零、错误 EOI、递归异常、丢失中断 |
| 进程 | 死循环、非法 syscall、退出泄漏 |
| IPC | 恶意长度、伪造句柄、撤销后使用、超时 |
| Supervisor | 服务崩溃、子进程逃逸、任务冻结和重启 |
| 设备 | 坏块、设备消失、网络断开、队列超时 |
| Agent | 恶意计划、窗口越权、token 重放、断网和取消 |
| 更新 | 坏模块、断电、健康检查失败、自动回滚 |

## 进入下一阶段的口试标准

学员需要能回答：

- 这条指令执行前后哪些寄存器改变？
- 这次内存访问经过了哪些页表项和权限检查？
- 删除某个检查会发生什么？
- 为什么这个错误不会拖垮其他进程？
- 失败时哪条日志或哪一个寄存器证明了根因？
- 如果把地址、设备或调用顺序换掉，哪些不变量仍然成立？
