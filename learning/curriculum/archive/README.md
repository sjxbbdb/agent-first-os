# 旧版课程资料

本目录记录学习方式迁移前的说明。旧课件、课后记录和实验代码仍然保留，方便追溯；它们不再决定当前学习入口。

本次重构前的完整课程文件可以从提交 `23487c7` 读取：

```bash
git show 23487c7:learning/curriculum/CURRICULUM.md
git show 23487c7:learning/curriculum/STUDY_PLAN.md
git show 23487c7:learning/curriculum/TEACHING_WORKFLOW.md
git show 23487c7:learning/curriculum/ASSESSMENT.md
git show 23487c7:learning/curriculum/RESOURCES.md
```

旧版的核心思路是“按基础课和视频阶段推进”；新版改为“按源码执行链推进”。旧内容仍可作为补课材料，但不会阻挡当前源码单元。

旧的 `C-PRE-01` 至 `C-PRE-06` 课后记录位于
`learning/notes/lesson-log/`，状态和迁移关系见
`learning/notes/INDEX.md` 与
`learning/notes/PROGRESS.md`。
