# M6：E820 启动内存图（第一小步）

日期：2026-09-13

本步在 BIOS 实模式调用 `INT 15h, E820h`，最多收集 32 个 24 字节条目到 `0x5000`，并把地址、条目数和条目大小写入 `BootInfo`。当前页表仍只恒等映射低 2 MiB，E820 解析后的物理帧分配器和高半内核迁移尚未实现。

验证命令：

```text
wsl.exe bash -lc "cd '/mnt/d/Agent OS' && bash product/tools/build-bios.sh && bash product/tools/run-bios.sh"
```

串口证据：

```text
KERNEL C OK
boot_info.magic=0x41474f53424f4f54
boot_info.version=0x0000000000000001
e820=[0x0000000000005000, count=0x0000000000000007, usable=0x0000000000000002]
vm.identity_end=0x0000000000200000 high_half_target=0xffffffff80000000 flags=0x0000000000000003
kernel=[0x0000000000100000, 0x000000000018004b]
pmm.ready=0x0000000000000001 first_page=0x0000000000200000
```

边界：已验证 QEMU/SeaBIOS 的 E820 传递、迁移布局记录和首个 4 KiB 页框选择；尚未验证真实固件差异、内存类型合并、复杂保留区过滤、并发分配、页故障恢复或高半映射切换。
