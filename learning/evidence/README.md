# 学习证据目录

## 命名和来源

| 前缀 | 含义 | 是否计入学员 SF Gate |
|---|---|---|
| SF-* | 源码主线单元的阅读、构建、运行和故障证据 | 是，需同时有口试和迁移题 |
| day-* | 早期 C/ELF 前置实验 | 只作历史补课 |
| M* | 产品实现阶段证据 | 否，属于工程状态 |
| G* | 产品验收/纵切证据 | 否，属于工程状态 |

现有 M1–M8、G1–G10 文件主要证明 product/ 某个 checkout 的实现曾经运行。它们不会自动证明学员能解释或重建同一机制。

## 单元证据格式

每份 SF 证据尽量包含：

- 源仓库、URL、commit、架构和工具链；
- 精确命令和原始输出；
- 运行前预测与实际差异；
- 一处改动；
- 故障注入、根因和恢复方式；
- 事实、推断、未验证项和环境限制；
- 对应 notes/lesson-log 记录。

截图可以辅助说明，但不能替代命令、日志或反汇编。没有实际运行的结果必须标为未验证。
