## 先理解“程序”

程序描述让计算机执行的操作。我们使用 C 语言写源代码，后续再学习怎样把它变成计算机能够执行的程序。

本课只看顺序执行的几行代码。你可以先扮演计算机，逐行记录数据的变化。

## 变量与赋值

```c
int count = 7;
count = count + 2;
```

第一行定义一个名叫 `count` 的整数变量，并把初始值设为 `7`：

- `int`：这里使用的整数类型；
- `count`：我们给变量起的名字；
- `7`：初始值；
- `;`：结束这条语句。

第二行是赋值：先读取右边的 `count`，算出 `7 + 2`，再把结果 `9` 存回左边的 `count`。`=` 在这里表示赋值；判断相等的写法以后再讲。

## 【重点】请记在平板上

请用自己的话记下这三点，并画出两个变量格子：

- 变量是有名字、能保存一个值的地方；
- 赋值按语句执行的顺序发生；
- `b = a + 2` 保存的是计算当时的结果，之后修改 `a` 不会自动修改 `b`。

再写一个你自己的例子，不要只抄上面的 `count`。

可以把这个变量暂时想成一个有名字、能存放整数的格子。这个比喻只用于跟踪值，内存位置与编译器实际实现以后再讨论。

## 当前唯一练习

不用运行，也不用查资料，按顺序阅读：

```c
int a = 3;
int b = a + 2;
a = 8;
```

说明执行完每一行后，已有变量的值分别是什么。尤其解释第三行执行后 `b` 是否改变，以及你的理由。

这段代码是函数体内的学习片段，还不是一个完整的可运行 C 程序。下一步会在理解值的变化之后，讲程序的完整外形，再一起运行它。
